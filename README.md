# 🗄️ Database Design and Development

This repository contains practical exercises, SQL scripts, tutorials, and in-class activities completed as part of the **Database Design and Development (DDD)** module at **SLIIT**.

The coursework focuses on developing practical database skills using SQL Server and Transact-SQL (T-SQL).

## 📚 Repository Contents

### 1. Laboratory Exercises

The `Labs/` directory contains SQL practical exercises from Labs 1–8.

| Lab | Main Topics |
|---|---|
| Lab 01 | SQL SELECT statements, filtering, sorting, aggregate functions and grouping |
| Lab 02 | SQL practical exercises |
| Lab 03 | Database creation and SQL exercises |
| Lab 04 | SQL practical exercises |
| Lab 05 | SQL practical exercises |
| Lab 06 | Views and user-defined functions |
| Lab 07 | Stored procedures, triggers and database operations |
| Lab 08 | Subqueries, nested queries and comparison operators |

### 2. Tutorials and In-Class Activities

The `Tutorials/` directory contains practical SQL exercises and classroom activities.

- **Week 01:** SQL queries, filtering, sorting, aggregate functions and grouping.
- **Week 02:** Table creation, constraints, data manipulation and joins.
- **Week 03:** Relational table design, primary and foreign keys, joins and grouped queries.

## 🛠️ Technologies Used

- Microsoft SQL Server
- Transact-SQL (T-SQL)
- SQL Server Management Studio (SSMS)

## 🎯 Learning Objectives

Through these practical exercises, I developed experience with:

- Writing SQL queries to retrieve and manipulate data.
- Creating database tables and defining relationships.
- Applying primary keys, foreign keys and constraints.
- Filtering, sorting and aggregating records.
- Performing operations across multiple related tables using joins.
- Creating views and user-defined functions.
- Working with stored procedures and triggers.
- Using subqueries to solve database problems.
